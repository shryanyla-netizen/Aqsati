# أقساطي — مشروع Android

## المحتويات
- تطبيق Android أصلي بلغة Kotlin.
- قاعدة بيانات SQLite محلية.
- إدارة الزبائن والعقود والدفعات.
- لوحة معلومات تعرض إجمالي العقود والمقبوض والمتبقي.
- واجهة عربية واتجاه RTL وعملة الدينار العراقي.

## البناء إلى APK
1. ثبّت Android Studio على الكمبيوتر.
2. افتح مجلد `AqsatiAndroid` من Android Studio.
3. اسمح بمزامنة Gradle وثبّت Android SDK 35 عند الطلب.
4. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
5. ستجد ملف APK عادةً في:
   `app/build/outputs/apk/debug/app-debug.apk`

## ملاحظات النسخة الأولية
- البيانات محفوظة محلياً في قاعدة SQLite داخل التطبيق.
- لا يوجد حالياً تسجيل دخول أو مزامنة سحابية.
- لا تحذف بيانات التطبيق قبل تصدير نسخة احتياطية؛ ميزة النسخ الاحتياطي داخل الواجهة ما زالت ضمن المرحلة التالية.
- هذا إصدار أولي وظيفي لإدارة السجلات الأساسية، ويحتاج اختباراً على جهاز فعلي قبل الاستخدام المالي الفعلي.
